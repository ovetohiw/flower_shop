# refs/

Визуальные референсы дизайна проекта: скриншоты, макеты, moodboard, кадры существующих экранов.

Ограничения UI для агента — [docs/convention/UIDESIGN.md](../docs/convention/UIDESIGN.md); карта — [docs/convention/index.md](../docs/convention/index.md). Библиотеки и способ стилей — [STACK.md](../STACK.md).

## Назначение

- Показать визуальную правду продукта до правок UI.
- Не заменяет UIDESIGN и STACK: референс задаёт направление; агентские конвенции и стэк задают ограничения.

## Когда читать

Перед изобретением или сменой UI: сначала эта папка, затем UIDESIGN, затем отмеченный Frontend / Стилизация в STACK.

Пустая папка допустима: внешних референсов нет — не выдумывайте второй визуальный язык «с нуля ради красоты»; повторите уже принятый паттерн репозитория или зафиксируйте открытое решение в плане / PROGRESS.md.

## Что класть

- PNG / JPG / WebP / PDF макетов и скриншотов
- Короткие заметки рядом допустимы (`*-notes.md`), не дублируйте UIDESIGN

Не кладите секреты, персональные данные и продакшен-токены на скриншотах.

## Именование

- Файл: `YYYY-MM-DD-short-topic.ext`
- Или подпапка по экрану / потоку: `onboarding/`, `settings/`, …
