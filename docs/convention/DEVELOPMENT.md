# DEVELOPMENT.md

**Для агента.** Канон: одна задача, стек-гейт, diff, имена, ошибки в коде, зависимости.
Не канон: sync / soft-hard / DoD / commit+push ([AGENTS.md](../../AGENTS.md)); слои / Mono-Micro ([ARCHITECTURE.md](./ARCHITECTURE.md)); секреты ([SECURITY.md](./SECURITY.md)); тесты ([TEST.md](./TEST.md)).
Читай при любой правке кода/доков задачи. Языки и команды — [STACK.md](../../STACK.md) / AGENTS.

### Связи

- Карта → [index.md](./index.md)
- Соседи: [ARCHITECTURE.md](./ARCHITECTURE.md) · [SECURITY.md](./SECURITY.md) · [TEST.md](./TEST.md) · [AGENTS.md](../../AGENTS.md)

**Нарушение** — правка шире задачи, технология вне стэка, код без проверки, соседний рефакторинг «заодно».

## Одна задача

- Одна фича или один фикс. Несвязанное не смешивай.
- Рефакторинг рядом — только если без него фичу нельзя сделать чисто.
- Не расширяй скоуп: «улучшения» без запроса — нарушение.
- Готовность — [AGENTS.md](../../AGENTS.md). Красная базовая верификация → чини до новой работы.
- Блокер/риск → PROGRESS.md. Молчаливый «потом» запрещён.

## Стэк

- Язык/фреймворк/библиотека/сервис вне STACK.md — запрещены.
- Стэк не выбирай «по пути» — hard: решение человека / STACK.md.
- Mono/Micro и слои — [ARCHITECTURE.md](./ARCHITECTURE.md) + STACK «Архитектура».
- Команды — AGENTS или STACK. Раннер не выдумывай; ручной сценарий ≠ верификация.
- Локальный инструмент вне репо не часть процесса, пока не в стэке.

## Diff

- Только нужное текущей задаче.
- Не переименовывай / не форматируй / не «причёсывай» соседний код.
- Документы вне задачи не трогай (кроме окончания сессии по AGENTS).
- Не удаляй чужой код, пока не ясно, что мёртвый и безопасно.
- Мультиподсистема → exec plan ([PLANS.md](../../PLANS.md)).

## Структура

- Код — туда, где уже живёт поведение. Второй слой «для удобства» запрещён.
- Повтори паттерн репо; новый паттерн — отдельное решение.
- Модуль — одна роль; не протаскивай БД/UI/внешний сервис через чужой слой.
- Публичный контракт важнее внутреннего удобства.
- Утилита — когда поведение уже повторяется, не «на будущее».
- Слои — [ARCHITECTURE.md](./ARCHITECTURE.md).

## Имена

- Имя = роль (`temp`, `data2`, `fix`, `utils2` запрещены).
- Не сокращай так, что смысл виден только этой сессии.
- Комментарий — зачем, если неочевидно; не пересказывай код.
- Закомментированный код / мёртвые ветки не оставляй.
- Магические числа поведения — именованные константы.

## Ошибки

- Сбой на границе — явный отказ/разбор/таймаут/пусто.
- Не глотай исключение и не подменяй пустым успехом.
- Наружу — понятный отказ без стека/SQL/путей ([SECURITY.md](./SECURITY.md)).
- Не лови шире нужного. Ошибки проверяй как счастливый путь ([TEST.md](./TEST.md)).

## Зависимости и конфиг

- Новая зависимость — нужна фиче и в STACK.md.
- Не тащи пакет ради одной строки, выразимой имеющимся.
- Конфиг вне репо; в репо — плейсхолдеры ([SECURITY.md](./SECURITY.md)).
- Debug-обход не коммить и не включай по умолчанию.
- Версии — как в репо; плавающая «последняя» без решения запрещена.

## Сессия

- Sync, DoD, commit+push, soft/hard — только [AGENTS.md](../../AGENTS.md).
- Нельзя проверить → hard в PROGRESS.md, не выдумывай успех.
